How to Host This Site Free Forever

Zero backend fees, infinite runtime, private to your devices.

Option 1: GitHub Pages (100% Free Forever)

  1. Create a free account on GitHub.com.
  2. Create a new public or private repository (e.g. my-vault).
  3. Upload this single index.html file directly.
  4. Go to Settings → Pages → Select main branch → Click Save.
  5. Your public vault URL is live instantly at https://yourusername.github.io/my-vault!

Option 2: Vercel or Netlify (Drag & Drop in 5 Seconds)

  1. Visit app.netlify.com/drop or vercel.com.
  2. Drag & drop a folder containing this index.html file.
  3. You get an instant high-speed HTTPS link with free CDN forever.
How files persist: All uploaded files are stored safely inside your browser's persistent IndexedDB Engine. They usually survive browser restarts, but browser storage can be cleared or evicted. Keep a separate backup for important files.
